# Enterprise RAG Platform

A production-style AI/ML platform learning project.

## Goals

- Build an AI inference API with Python and FastAPI
- Implement document retrieval and RAG
- Integrate Amazon Bedrock
- Containerize the application using Docker
- Automate testing and deployment with GitHub Actions
- Deploy and monitor the application on AWS

## Current Status

Day 1: Project initialization.

## Local Setup

```bash
python3 -m venv AWS_env
source AWS_env/bin/activate
python -m pip install -r requirements.txt
python -m app.main
```
